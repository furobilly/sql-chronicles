    Tutorial — Nivel 0: ¿Qué hace SELECT?

    SELECT se utiliza para pedir columnas de una tabla.

    SELECT title, author FROM books;
    1. SELECT — define qué columnas quieres.
    2. FROM — indica la tabla de la que quieres leer.
    3. WHERE (opcional) — filtra filas por condiciones.

    Ejemplo paso a paso:

    SELECT title, author FROM books;

    - title y author son columnas. books es la tabla. Si no conoces columnas usa "¿Qué tablas hay?".
